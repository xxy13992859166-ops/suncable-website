Typical Applications

A combiner box gathers the output of several PV strings into one feed to the inverter, and provides a single point for isolation and surge protection. Multiple input configurations cover everything from a small rooftop array to a multi-string commercial installation.

  • Rooftop commercial and residential arrays
  • Ground-mount string consolidation
  • Projects requiring string-level isolation
  • Outdoor installations needing an IP65 enclosure
