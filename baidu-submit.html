Baidu Webmaster Tools

Submit your site to Baidu for Chinese-language organic traffic and APAC coverage.

Step 1: Register at Baidu Zhanzhang

  1. Go to ziyuan.baidu.com (Baidu Webmaster Platform)
  2. Sign in with Baidu account (need Chinese phone number) or use third-party login
  3. Click "网站添加" (Add Site) and enter: https://xxy13992859166-ops.github.io/suncable-website/
Submit to Baidu

Step 2: Verify Ownership

  1. Baidu offers multiple verification methods:
  2. HTML tag: Add meta tag to your HTML head
  3. DNS TXT: Add TXT record to your domain DNS (most reliable)
  4. File upload: Upload verification file to site root
  5. For GitHub Pages, use DNS TXT verification

Step 3: Submit Sitemap

  1. After verification, go to "站点管理" > "Sitemap"
  2. Add your sitemap: https://xxy13992859166-ops.github.io/suncable-website/sitemap.xml
  3. Baidu also accepts the API push method for real-time submission
Submit Sitemap to Baidu

Step 4: Use Baidu Push API

Baidu provides an API for real-time URL submission (better than sitemap alone):

curl -H "Content-Type:text/plain"   "http://data.zz.baidu.com/urls?site=xxy13992859166-ops.github.io&token=TOKEN"   --data-binary @urls.txt

Replace TOKEN with your Baidu Zhanzhang API token. Create urls.txt with one URL per line.

Baidu SEO Tips: Baidu prioritizes Chinese-language content and sites hosted in Asia-Pacific. Consider adding a Chinese version of your site. Baidu also values internal linking and site structure heavily. Baidu crawls slower than Google for non-Chinese sites, so be patient (2-4 weeks for initial indexing).
