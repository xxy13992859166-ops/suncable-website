Solar Cable Retrofit: Replacing Old PV Systems Safely

Guide to solar cable replacement in existing installations. When to replace, safety procedures, and code compliance for retrofits.

💬 Chat on WhatsApp

Replace the cable, or the whole DC side?

On a retrofit the cable is rarely the only degraded component. Connectors, string fuses and sometimes the modules themselves are at end of life too. Deciding what to keep is an economics question with a safety floor: anything that cannot be shown to be sound should not be re-energised.

When replacement is not optional

  • Jacket cracking or chalking along a run — the compound has aged out, and the conductor underneath is no longer protected.
  • Insulation resistance to earth that has fallen below the value recorded at commissioning and continues to fall.
  • PVC or unknown-origin cable on a DC array, whatever it looks like.
  • Undersized runs that were marginal at commissioning and are now carrying more current after an array expansion.
  • Any cable that has been wet internally — water travels along strands and corrosion continues after the visible damage is gone.

The safe sequence

  1. Isolate and lock off, and treat the DC side as live until proven otherwise — a string in daylight is a source, not a load.
  2. Measure and record insulation resistance per string before disturbing anything; that baseline is what proves the new installation is better.
  3. Remove and label; photograph the routing before it is dismantled.
  4. Replace connectors as well as cable where the connector age is unknown — a new cable on an old joint moves the failure point, it does not remove it.
  5. Re-test per string and compare with the pre-works record.

Partial replacement traps

Replacing one string run and leaving its neighbours is common and usually fine, provided the new cable matches the old in size and construction. Mixing sizes on parallel strings creates unequal current sharing, and mixing old PVC with new XLPO creates two different ageing rates on the same array. Match, or replace the set.

SituationDecision
Cracked jacket on one runReplace the run; inspect adjacent runs
Falling insulation resistanceInvestigate joints first, then replace
Array expanded, runs marginalRe-size on the new current
Unknown-origin cableReplace regardless of appearance

Documenting the retrofit

Record the cable type, size, batch and test results for the replaced sections. A retrofit without that record becomes an unknown-origin installation the next time someone inspects it — which is where the cycle starts again.

For replacement quantities, send the run list and string count to the quotation page; PV1-F and H1Z2Z2-K are available with the documentation an inspector will ask for.
