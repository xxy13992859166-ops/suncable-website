Solar Cable Installation Guide

Proper installation is critical for solar system safety and longevity. Follow these best practices for routing PV cables and connecting MC4 connectors.

Tools Needed

  • MC4 crimping tool (brand-specific dies)
  • Wire strippers (1.5-16mm² range)
  • Solar cable clips (UV-resistant)
  • Cable trunking or conduit
  • Multimeter for testing
  • UV-resistant cable ties

Installation Steps

1. Plan Cable Routes

Map routes from panels to inverter. Keep paths short to minimize voltage drop. Allow extra length for connections.

2. Mount Cable Clips

Install clips every 30-50cm on rooftops. Use UV-rated solar clamps—never staple or nail through insulation.

3. Run the Cables

Thread PV1-F or H1Z2Z2-K through clips. Maintain minimum bend radius of 5x cable diameter. Avoid sharp bends.

4. Install MC4 Connectors

Crimp using correct tool and die. Test each connection with a multimeter before attaching to panels.

5. Label Everything

Label both ends of each cable run. Keep an as-built diagram for maintenance reference.
